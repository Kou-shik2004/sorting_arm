# sorting_arm_moveit

MoveIt 2 configuration for the sorting arm: planning groups, named states,
kinematics, and controller wiring. Generated by the MoveIt Setup Assistant from
`sorting_arm_description`'s URDF, and versioned like any other package from
there on.

You won't normally launch anything in this package directly. `sorting_arm_bringup`
includes `move_group.launch.py` and `moveit_rviz.launch.py` from every launch file
that needs planning, so start from there instead.

## Regenerating the configuration

```bash
ros2 launch sorting_arm_moveit setup_assistant.launch.py
```

Opens the MoveIt Setup Assistant against this package's `.setup_assistant` file.
Re-running Screen 8 (ROS 2 Controllers) resets `sorting_arm.ros2_control.xacro` to
whatever interfaces the Assistant knows about by default, so check that file
against `sorting_arm_description`'s xacro after any regeneration.

## What you might change

| File | Controls |
|---|---|
| `config/sorting_arm.srdf` | Planning groups and named states, including `home` and `gripper_close`. |
| `config/joint_limits.yaml` | Per-joint velocity and acceleration scaling used by the planning pipeline. |
| `config/moveit_controllers.yaml` | Which controller MoveIt sends trajectories and gripper commands to. |
| `config/moveit.rviz` | The default MoveIt Motion Planning RViz layout. |
