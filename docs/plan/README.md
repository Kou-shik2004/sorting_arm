# Implementation plans

The [implementation roadmap](roadmap.md) defines the active project stage, ordered
work, verification requirements, and completion gates.

[Continuous integration](continuous-integration.md) defines the three validation
levels that grow alongside the roadmap rather than beginning after feature
implementation is complete.

[Future interfaces, actions, and executive](future-actions-executive.md) records the
planned application contracts and orchestration design for the later roadmap stages.
Those components remain planned until their prerequisite gates pass.

[Deployment experience](deployment-experience.md) defines the final runtime image,
Compose profiles, visible sorting cycle, recovery presentation, and completion
evidence expected from a clean checkout.
